# 🍬 Candy Crush Hogwarts — Phù Thủy Đại Chiến (Season 1: 100 Bản Đồ)

Game Match-3 chủ đề thế giới phù thủy Harry Potter Việt Nam (HPVN), lấy cảm hứng từ lối chơi kinh điển Candy Crush Saga kết hợp Kẹo Đậu Đủ Vị Bertie Bott & Thẻ Ếch Sô-cô-la Pháp Thuật.

## 🌟 Tính Năng Nổi Bật

- **100 Màn Chơi (Season 1)**: Hệ thống bản đồ phiêu lưu qua các chương Hogwarts, Hẻm Xéo, Rừng Cấm và Hồ Đen.
- **Cơ chế Match-3 Đầy Đủ**:
  - Kẹo sọc (Striped), Gói kẹo nổ (Wrapped), Kẹo Đậu Bảy Màu (Color Bomb).
  - Kết hợp combo đôi thần thánh (Color Bomb + Wrapped, Double Color Bomb, Striped + Wrapped,...).
  - Chướng ngại vật phong phú: Thạch Đậu (Jelly), Sô-cô-la nhân bản, Khóa phép, Rào gai, Bọt nước,...
- **Phép Thuật & Booster**:
  - Búa Kẹo Nổ Dumbledore, Đũa Cơm Nguội Đổi Chỗ, Cú Hedwig Giao Hàng,...
  - Vòng quay may mắn hàng ngày (Daily Wheel) & Rương thưởng Ngôi sao (Star Chests).
- **Bộ Sưu Tập Thẻ Phù Thủy Ếch Sô-cô-la**: Mở khóa các thẻ bài huyền thoại khi hoàn thành mục tiêu.
- **Hệ Thống Nhà Hogwarts**: Lựa chọn Nhà (Gryffindor, Slytherin, Ravenclaw, Hufflepuff) với giao diện hiệu ứng riêng biệt.
- **Lưu Trữ Tự Động**: Lưu trữ tiến trình chơi, tim, vàng và vật phẩm qua LocalStorage an toàn.

## 🚀 Cài Đặt & Chạy Cục Bộ

1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

2. Chạy môi trường phát triển (Dev server):
   ```bash
   npm run dev
   ```

3. Đóng gói cho Production:
   ```bash
   npm run build
   ```

4. Xem trước bản đóng gói:
   ```bash
   npm run preview
   ```

## 🛠 Công Nghệ Sử Dụng

- **Engine & Core**: Vanilla JavaScript (ES Modules), HTML5 Canvas 2D Renderer.
- **Giao Diện**: Modern CSS, Responsive Design tối ưu cho cả Mobile & Desktop.
- **Bundler**: Vite 6.
- **Triển Khai**: Vercel & GitHub.
